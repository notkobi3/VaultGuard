# Chrome Web Store Listing Draft

## Short Description

Local phishing-risk checks for important financial, crypto, cloud, and login domains.

## Long Description

VaultGuard helps users spot suspicious look-alike domains before trusting important login pages.

It checks website hostnames locally in the browser and displays an explainable risk score, risk level, and reason list. VaultGuard is designed for financial accounts, crypto wallets, brokerages, cloud services, developer tools, and other high-value accounts.

VaultGuard can be used manually from the extension popup. Users can also enable optional auto-scan to update the toolbar badge as pages load. High-risk pages can show an optional warning banner.

Current features:

- Local hostname risk analysis.
- Protected-brand list.
- Trusted-domain list for known-safe false positives.
- Optional auto-scan.
- Optional high-risk warning banner.
- Hostname-only local history.
- History filters and JSON/CSV export.
- Company policy presets.
- Policy import/export.
- Trusted level for manually approved domains.
- Contextual scoring that avoids penalizing normal university or business domains for login-related words alone.

VaultGuard does not ask for passwords, seed phrases, private keys, recovery codes, bank details, API keys, or payment card numbers.

VaultGuard does not send browsing data to a VaultGuard server.

Important: VaultGuard helps identify suspicious domain patterns, but it cannot guarantee that a website is safe or prevent every phishing attempt.
