# VaultGuard Legal and Trust Documents

These documents are working drafts for the VaultGuard project. They should be reviewed by a qualified attorney before VaultGuard is sold, published broadly, or offered to business customers.

## Documents

- `privacy-policy.md`: explains what VaultGuard does and does not collect.
- `terms-of-service.md`: explains basic usage terms, disclaimers, payments, and support boundaries.
- `security-overview.md`: explains the security model, permissions, and data-handling posture.
- `permissions.md`: maps each Chrome permission to its purpose and risk.
- `vulnerability-disclosure.md`: gives users and companies a way to report security issues.
- `update-checklist.md`: reminds the project owner when these documents need to be updated.

## Update Rule

Update these documents whenever VaultGuard changes how it:

- Reads website URLs or page data.
- Stores user settings, history, or account information.
- Sends data to any server or third-party service.
- Adds, removes, or changes Chrome permissions.
- Adds paid features, subscriptions, company accounts, or licensing.
- Adds account login, team management, analytics, telemetry, or support workflows.
