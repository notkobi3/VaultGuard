# Legal and Trust Document Update Checklist

Use this checklist before every release.

## Release Checks

- Did `manifest.json` permissions change?
- Did VaultGuard begin reading more than hostnames?
- Did VaultGuard begin storing history, trusted sites, or user account data?
- Did VaultGuard add analytics, telemetry, crash reporting, or logs?
- Did VaultGuard add a backend, cloud sync, login, or team dashboard?
- Did VaultGuard add payment, subscription, licensing, or business customer features?
- Did VaultGuard add third-party integrations?
- Did VaultGuard add or change feedback, support, or reporting workflows?
- Did marketing copy make stronger security claims?
- Did support contact, company name, or ownership change?

## If Yes

Review and update:

- `privacy-policy.md`
- `terms-of-service.md`
- `security-overview.md`
- `permissions.md`
- `vulnerability-disclosure.md`
- Chrome Web Store privacy disclosures
- Store listing copy and screenshots

## Commercial Release Reminder

Before charging companies or publishing broadly, have the documents reviewed by a qualified attorney. These drafts are project planning documents, not legal advice.
