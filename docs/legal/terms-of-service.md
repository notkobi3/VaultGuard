## Product

VaultGuard is an educational browser extension that helps identify phishing-style domain risks by analyzing website hostnames locally in the browser.

## Important Disclaimer

VaultGuard helps identify suspicious domain patterns, but it cannot guarantee that a website is safe. Users remain responsible for verifying websites before entering sensitive information, signing transactions, sending money, logging into accounts, or approving financial actions.

VaultGuard should not be treated as a replacement for security training, password managers, hardware security keys, antivirus tools, endpoint protection, fraud monitoring, or professional security review.

## Acceptable Use

Users may use VaultGuard to:

- Review website hostnames for phishing-style risk signals.
- Maintain a local protected-brand list.
- Display local risk explanations and warning banners.

Users may not use VaultGuard to:

- Misrepresent security guarantees.
- Claim that VaultGuard proves a website is safe.
- Reverse engineer, resell, or redistribute paid versions unless a license allows it.
- Use VaultGuard for unlawful activity.
